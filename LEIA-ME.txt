CONVITE FERNANDO MIGUEL — ARQUIVOS PRONTOS PARA GITHUB E RENDER

Os arquivos deste ZIP já estão todos juntos na raiz. Não crie pastas.

1. Extraia o ZIP no celular ou computador.
2. No GitHub, abra o repositório Fernando-Miguel-.
3. Toque em Add file > Upload files e envie TODOS os arquivos extraídos.
4. Confirme em Commit changes.
5. No Render, configure o Static Site assim:
   Branch: main
   Root Directory: deixe vazio
   Build Command: echo ok
   Publish Directory: .
6. Salve e faça Manual Deploy > Deploy latest commit.
