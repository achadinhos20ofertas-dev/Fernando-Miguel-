CONVITE DO FERNANDO MIGUEL — ARQUIVOS PARA GITHUB E RENDER

O site é estático. As páginas e imagens estão na pasta dist.

PUBLICAR NO RENDER
1. Extraia este ZIP e envie os arquivos para um repositório no GitHub.
2. No Render, escolha New > Static Site e conecte o repositório.
3. Deixe Root Directory vazio.
4. Build Command: echo "Site estático"
5. Publish Directory: dist
6. Clique em Create Static Site.

A página principal é dist/index.html. O convite usa as imagens em dist/assets.
